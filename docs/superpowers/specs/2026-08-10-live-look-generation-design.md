# Design: Live look generation + quality gate

**Date:** 2026-08-10
**Status:** Approved (design), pending operator sign-off on the pinned Claude
model id + pricing and the new `SHOPSTEWARD_LIVE_LOOK` live flag.
**Builds on:** the mass-mode RAW auto-edit engine (`docs/superpowers/specs/2026-08-09-raw-auto-edit-engine-design.md`, shipped in PRs #20/#21).

## Background

The engine can apply a named/hand-authored look, and the OpenRouter look
adapter exists and is tested — but the CLI defaults to the offline
`FixtureLookAdapter`, so a free-text `--look "cinematic mexico"` produces a
deterministic *placeholder*, not a real LLM grade. This effort wires live look
generation into the CLI (gated, opt-in) and adds a quality gate so a bad
generation can never silently grade a whole shoot. Closes the original
"describe a look and feel" ask.

**Model decision:** looks are generated by a **Claude** model via OpenRouter
(operator choice — best at translating an evocative phrase into a tasteful
grade). Generated rarely, then reused, so per-call cost is acceptable.

## Architecture constraints

The editing module is standalone: import-linter forbids `shopsteward.editing`
from importing `shopsteward.pipeline` (including `pipeline.live_gate`,
`pipeline.tuning`, `pipeline.llm_ledger`). Therefore the look gating, LLM
config, and cost ledger for this feature are **editing-module-local**, mirroring
the pipeline conventions rather than reusing them. The look adapter already
lives at `src/shopsteward/adapters/look/` and is legal for editing to import.

## #1 — Live look generation wired to the CLI

### Gating (`src/shopsteward/editing/live_look.py`)
- `live_look_open() -> bool`: true iff `SHOPSTEWARD_LIVE_LOOK=1` **and**
  `OPENROUTER_API_KEY` is set. Mirrors `pipeline.live_gate.live_copy_open`.
- `live_look_error() -> str`: refusal message naming the flag + env var + the
  `--live-look` CLI flag.

### CLI
- `edit run` gains `--live-look` (default `False`). Resolution rule:
  - A look that resolves to a **stored name or an already-saved described look**
    never calls the LLM (unchanged).
  - A **new described look** with `--live-look` set **and** `live_look_open()`
    true → build `OpenRouterLookAdapter` and generate.
  - Otherwise → `FixtureLookAdapter` (current offline behavior). If
    `--live-look` is passed but the gate is closed, refuse up front with
    `live_look_error()` (do not silently fall back to the fixture).

### Config (`config/defaults/editing.json`, new `look_llm` block)
```json
"look_llm": {
  "provider": "openrouter",
  "model": "<pinned Claude OpenRouter id — confirmed at build>",
  "temperature": 0.7,
  "pricing": { "<model>": { "in": 0.0, "out": 0.0 } },
  "monthly_soft_cap_usd": 5.0
}
```
Config accessor `load_look_llm()` in `editing/config.py`.

### Cost control (editing-local, event-sourced)
- On each live generation with usage, append an `llm.call` event via
  `core.events` with `{feature: "look", model, input_tokens, output_tokens,
  est_cost_usd, description}`.
- Before generating, sum the current UTC month's look `llm.call` costs; if the
  sum ≥ `monthly_soft_cap_usd`, **refuse** with a clear message (hard soft-cap —
  prevents runaway spend; operator raises the cap in config to proceed).
- The `FixtureLookAdapter` returns `usage=None`, so offline runs never emit an
  `llm.call` event (matches the copy-adapter convention).

### Adapter note (build-time verification)
`OpenRouterLookAdapter` sends `response_format: {type: json_schema, strict:
true}`. Structured-output support varies by model on OpenRouter; confirm the
pinned Claude model honors it. If it does not, fall back to prompt-guided JSON
(the adapter already raises `LookParseError` on unparseable output, which the
resolver's retry handles). Confirm current Claude OpenRouter id + pricing via
the `claude-api` / `find-docs` skill during the build.

## #3a — Auto sanity guard (deterministic)

`sanitize_look(profile: LookProfile, knobs: dict) -> LookVerdict` where
`LookVerdict = {ok: bool, reason: str | None}`. Runs **only on freshly
LLM-generated looks** — hand-authored seed/stored looks are trusted and skip the
guard. Bounded aggregate checks (thresholds in a `look_guard` config block):
- **Total saturation load**: `|vibrance| + |saturation| + sum(|hsl saturation
  adjustments|) + split-tone saturations` over a cap → reject.
- **Combined contrast/tone steepness**: `|contrast|` plus a tone-curve steepness
  measure over a cap → reject.
- **Presence extremes**: `|clarity| + |dehaze| + |texture|` over a cap → reject.
- **Split-tone saturation** individually over a cap → reject.

On reject, the resolver: **regenerate once**; if the retry also fails the guard,
**fall back to a configured default seed look** (`look_guard.fallback_look`,
e.g. `bright-and-true`) and record the fallback in the returned profile's
description + an event. So a garish generation can never reach a full batch.

Thresholds are calibration knobs (config-over-code); starting values are
deliberately permissive and tunable.

## #3b — A/B preview command

`shopsteward edit look preview <sample_dir> --look "<desc|name>" [--against
<seed>] [--live-look]`:
- Ingests the RAWs in `<sample_dir>` (RAW-only ok), resolves the candidate look
  (generating if described + `--live-look`), and loads the `--against` seed
  (default `bright-and-true`).
- Writes a `_preview/` dir with `candidate/` and `<seed>/` subfolders; into each,
  copies the sample RAWs and writes that look's sidecar (per-image correction is
  identical across both, so the comparison isolates the look).
- Prints both looks' key develop values side by side.
- Operator imports both subfolders into Lightroom, compares, then runs the real
  `edit run` (or tweaks / re-generates). Non-destructive: writes only under
  `_preview/`.

## Testing (fixtures only — no live APIs)

- `live_look`: `live_look_open`/`error` via monkeypatched env.
- Adapter-swap: `edit run --live-look` builds the live adapter only when the gate
  is open; refuses when passed but closed; uses the fixture otherwise.
- Sanity guard: synthetic garish profile → `ok=False`; tasteful profile →
  `ok=True`; resolver retry-then-fallback path with a `FakeLookAdapter` queue.
- Cost ledger + soft cap: seed `llm.call` events over the cap → generation
  refused; under the cap → allowed; `llm.call` emitted with usage.
- Live OpenRouter path: exercised only via `respx` mocks (Claude response shape).
- Preview command: stub RAWs + fake decoder/adapter → asserts `_preview/`
  structure and both sidecars written.
